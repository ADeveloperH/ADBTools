# ADB 项目导入

## 适用场景

当前目录里有项目配置压缩包，需要把里面的项目导入或更新到 `config/projects.json` 时使用这个 skill。

## 处理流程

1. 在当前目录找到压缩包。
2. 解压出里面的工作簿。
3. 读取工作簿并找到项目总表。
4. 提取每个项目的稳定字段：
   - `AppName`
   - `GPStoreName`
   - `CompanyName`
   - `PackageName`
5. 将提取出来的项目合并进 `config/projects.json`。
6. 除非相同包名已存在，否则保留已有配置中的人工修改。

## 规则

- 优先使用当前目录里的压缩包，不要扫描无关目录。
- 如果压缩包里有多个工作簿，使用找到的第一个 `.xlsx` 文件。
- 以 `PackageName` 作为唯一键。
- `GPStoreName` 存在时作为 `project_name`，否则回退到 `AppName`。
- 在保存的项目记录里保留 `store_name` 和 `company_name`。
- 跳过没有包名的行。
- 如果工作簿结构和预期不一致，直接停止并报告，不要猜。

## 输出

需要报告：

- 使用的压缩包文件
- 导入了多少个项目
- 更新了多少条已有记录
- 跳过了多少行
- 新增了哪些项目
- 更新了哪些项目
- 哪些项目只是命中但字段未变化

实际导入逻辑使用随 skill 附带的脚本。
